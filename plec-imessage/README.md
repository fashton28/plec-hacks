# PLEC in your group chat

An iMessage agent that joins a friend group chat, quietly keeps a living plan of the party, and helps the group pick, book and manage a venue.

```bash
cd plec-imessage && cp .env.example .env   # add LLM_API_KEY + PLEC_SANDBOX_KEY
npm run sim                                 # terminal group chat
```

See NOTES.md for details.
